## Featured Projects

### 🏥 LifeCare: Hospital Management Platform
Full-stack hospital management system with role-based portals for Patients, Doctors and Admins.
- 15+ RESTful API endpoints covering appointment scheduling, prescriptions and billing
- Normalized MySQL schema with 6 entities, foreign key constraints and indexed columns
- **Stack:** React, Node.js, Express, MySQL, REST APIs

### 🧠 Business Entity Resolution (Amazon ML Challenge 2026)
Pipeline that matches business records across 3 noisy data sources and generalizes to a country not seen in training.
- Blocking stage to cut the candidate pair space before pairwise matching
- Trained on AWS EC2, reaching 0.65 macro F0.5
- **Stack:** Python, NumPy, Pandas, Scikit-Learn, AWS

### 🩺 HealthMentor (ByteVerse Hackathon 2025)
Health-checking web app that uses the Google Gemini API, built with a team of 4 at NIT Patna.
- **Stack:** Web stack with Google Gemini API

### 🌍 Travel Discovery App
App for discovering restaurants, hotels and attractions, with live location search and Google Maps integration.
- **Stack:** React, Material UI, Google Maps API

### 🧩 Daily LeetCode POTD
Repository of daily LeetCode Problem of the Day solutions, tracking consistent DSA practice.

### 🎨 Frosted Glass Calculator and Notebook-Style To-Do App
Two front-end projects focused on UI styling: a glassmorphism calculator and a to-do list that looks like a physical notebook.
- **Stack:** HTML, CSS, JavaScript
